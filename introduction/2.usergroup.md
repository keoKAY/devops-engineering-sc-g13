- Group Related Commands 
```bash

cat /etc/group

sudo usermod -aG developer $USER
# check group and userid 
id james 

tldr groupmod  # change name, id 
tldr deluser 
# remove james from developer group 
sudo deluser james developer
```

- Ownership 
```bash 
tldr chown 

sudo chown james:james myscript.sh
sudo chown james: myscript.sh 
# change only group owner 
sudo chown :vagrant myscript.sh

# change only owner user 
sudo chown vagrant myscript.sh 
```

## Customizing the Priviledges 
```bash
sudo usermod -aG sudo james


sudo useradd -m -s /bin/bash deploy-agent 
echo "deploy-agent:123" | sudo chpasswd


# customize priviledge for deploy-agent user 
sudo visudo 
# go to the last line 
deploy-agent ALL=(ALL:ALL) NOPASSWD:ALL

```
